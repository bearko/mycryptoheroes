# WebGL ヒーロー図鑑

`Data/Heroes/heroes.json` と `Image/Heroes/*.png` を使って、ヒーロー404体をWebGLで一覧・検索できる図鑑ビューアです。外部ライブラリは使わず、素のWebGL（WebGL2、無い場合はWebGL1 + `ANGLE_instanced_arrays`）とES Modulesだけで動きます。

## 起動方法

このビューアは `fetch` でJSONを読むため、`file://` では動きません。リポジトリのルートで静的サーバーを立てて開いてください。

```bash
# リポジトリのルートで実行
python3 -m http.server 8000
# => http://localhost:8000/WebGL/HeroCompendium/
```

Node.jsを使う場合は `npx http-server -p 8000` でも同じです。

## できること

| 機能 | 内容 |
|------|------|
| 一覧 | 404体をインスタンス描画で1ドローコール表示。ドラッグで移動、ホイール/ピンチで拡大縮小 |
| 配置切り替え | **グリッド**（並べ替え順）、**勢力**（四神ごとのかたまり）、**PHY×INT**（最大レベルステータスの散布図） |
| 絞り込み | レアリティ段位、勢力、区分（オリジナル/レプリカ/コラボ/ノービス/その他）、属性、パッシブ演出、フリーワード検索 |
| 並べ替え | ID / 名前 / 合計値 / レアリティ / HP / PHY / INT / AGI |
| 詳細表示 | 最大レベル・初期ステータス、パッシブスキル（アイコン付き）、属性、エンチャント、発行数、Wikipediaリンク |
| 演出再生 | 選択したヒーローのパッシブスキルの `effect_id` に対応するバトルエフェクトスプライトを再生。`SE` をONにすると対応する効果音も鳴る |
| 多言語 | UIとヒーロー名・スキル文の日本語/英語切り替え |
| 共有 | 選択中のヒーローが `#hero=1001` としてURLに入るため、そのまま共有できる |

キーボード: `/` で検索、`F` で全体表示、`Esc` で詳細を閉じる。

## 参照しているリポジトリ内アセット

| パス | 用途 |
|------|------|
| `Data/Heroes/heroes.json` | ヒーローマスタ（名前、ステータス、パッシブ、属性、エンチャント） |
| `Image/Heroes/*.png` | 64x64のヒーロー画像。テクスチャアトラスに統合して描画 |
| `Image/BattleIcons/**` | パッシブスキルのアイコン（`passive.icon_file_name` から解決） |
| `Data/Effects/battle_effect_sprites.json` / `Image/Effects/Battle/*.png` | パッシブ演出のスプライトシート |
| `Data/SoundEffects/battle_sound_effects.json` / `Audio/SE/Battle/*.mp3` | パッシブ演出のSE |
| `Image/Icons/mch_icon.png` | ファビコンとヘッダーロゴ |

マスタ側にしか存在しないアイコン（`agi.png` / `barrier.png` / `BUF_chg.png`）は画像を持たないため、アイコンなしで表示します。

## 実装メモ

- **テクスチャアトラス**: 64x64の画像を 2048x2048（32x32セル）のテクスチャへ `texSubImage2D` で流し込みます。読み込めた画像から順に反映されるので、全件のダウンロードを待たずに操作できます。
- **ドット絵の拡大**: フィルタは `NEAREST`、ミップマップなし。リポジトリのガイドライン通りニアレストネイバーで拡大します。
- **インスタンス描画**: カード1枚あたり `vec4` × 5（座標/サイズ、アトラスUV、レアリティ色、勢力色、状態）の20 floatを毎フレーム転送し、単位クアッドをインスタンス描画します。
- **カードの見た目**: 角丸、レアリティ枠、レプリカ用の内側の線、左上の勢力ウェッジ、ホバー/選択時のグロウはすべてフラグメントシェーダーで生成しています（画像素材なし）。
- **アンチエイリアス**: WebGL1で `fwidth` が使えない環境を考慮し、カードの画面上サイズから頂点シェーダーでAA幅を求めています。
- **背景**: ワールド座標に固定したグリッドと、選択中/絞り込み中の色をうっすら混ぜるフルスクリーンシェーダー。
- **ピック判定**: レイアウトはCPU側にも持っているため、カーソル位置のワールド座標とカード矩形の交差判定で行っています（GPUピッキングは不要）。

## ファイル構成

```
WebGL/HeroCompendium/
├── index.html          エントリポイント
├── css/app.css         キャンバスに重ねるUIのスタイル
└── js/
    ├── main.js         状態管理と描画ループ
    ├── gl-core.js      WebGLコンテキスト / シェーダー / バッファのラッパー
    ├── scene.js        背景・カード・エフェクトの3つの描画パス
    ├── camera.js       2D正射影カメラ（パン / ズーム / フィット）
    ├── atlas.js        ヒーロー画像のテクスチャアトラス
    ├── layout.js       グリッド / 勢力 / 散布図のレイアウト計算
    ├── effects.js      パッシブ演出スプライトとSEの再生
    ├── heroes.js       heroes.json の正規化・絞り込み・並べ替え
    ├── ui.js           DOM側のUI組み立て
    └── i18n.js         UI文言（ja / en）
```

## 動作要件

WebGL2、またはWebGL1 + `ANGLE_instanced_arrays` に対応したブラウザ。ES Modulesを使うため、Chrome / Edge / Firefox / Safari の現行版が対象です。
